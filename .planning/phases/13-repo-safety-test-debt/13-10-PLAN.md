<objective>
Build the skip-marker relay Tim chose (D-06 amendment, option A): a `pull_request_target` workflow that never touches PR code, notices a skip marker on a same-repo PR head that GitHub really skipped, dispatches the normal `ci.yml`, waits for it and reports its conclusion under the check name `CI OK`. Checks from `workflow_dispatch` runs do not satisfy rulesets; a `pull_request_target` job does, which is why the relay mirrors instead of relying on the dispatched run.

Purpose: the GSD ship note (`... [ci skip]`) must get a final, real `CI OK` on its head SHA instead of staying pending (GUARD-08).
Output: `ci-skip-relay.yml` and the guard rules that keep it safe.

Canon note: running PR code under `pull_request_target` ("pwn request") and script injection are canon security risks covered by the threat model below and `/gsd-secure-phase`; they are not minted as bespoke prohibitions here.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR (possibly a fork) → pull_request_target | Runs with the base repo's token; PR content is untrusted |
| Relay → Actions API | `actions: write` dispatches ci.yml |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-22 | Elevation of privilege | relay under pull_request_target | critical | mitigate | No checkout and no PR code; guard rule 10; dispatched ci.yml runs with its own `contents: read` |
| T-13-23 | Tampering | head ref and commit message in shell | high | mitigate | Only through `env:`, quoted; guard rule 11 bans expressions in run blocks |
| T-13-24 | Spoofing | fork PR with a marker | high | mitigate | Fork head → relay CI OK fails red; never dispatches |
| T-13-25 | Elevation of privilege | token scope | medium | mitigate | `permissions: {}` top level; `actions: write` only on the relay job; guard rule 14 |
| T-13-26 | Elevation of privilege | vacuous CI OK via skipped job | high | mitigate | No job-level `if:` on the relay job (guard rule 12); dynamic name instead |
| T-13-27 | Denial of service | relay never reports | medium | mitigate | 100-minute job timeout; fails when the dispatched run is not found or moved SHA |
| T-13-SC | Tampering | npm installs | low | accept | No package install in this plan |
</threat_model>
