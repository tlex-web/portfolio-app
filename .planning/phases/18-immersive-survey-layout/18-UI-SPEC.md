# Phase 18 — UI Design Contract

> Visual and interaction contract for Phase 18 (Immersive Survey Layout). Generated by gsd-ui-researcher, to be verified by gsd-ui-checker.
>
> **Scope (ROADMAP "UI-SPEC" note):** the Alps overview on `/photos` (sheet-index rectangles, reference summits, labels at 375 px, HTML pin overlays, synced region list); the region page at `/photos/regions/<id>` (header band, the header slot Phase 19 fills, facts, local plate with photo pins, the uncropped sequence, the map collar, the altimeter rail, the next-region block); the region-scoped lightbox with its end-of-series card; Share / Copy link; the LV95 line; the coarse-location treatment; every map's sheet margin; the footer's Source row; the new `/sources` page; the breadcrumb on region and photo pages.
>
> **Baseline:** the v2.0 "Topographic" system. `07-UI-SPEC.md` (tokens v2, focus ring, shell), `08-UI-SPEC.md` (footer sheet margin), `09-UI-SPEC.md` (altimeter rail, summit mark), `10-UI-SPEC.md` (map sheet, lightbox, strip, stepping, focus return) and `14-UI-SPEC.md` (step buttons, LBOX-08 focus geometry) are inherited unchanged except where a row below says otherwise. **No new colour token, no new type size or weight, no new font, no new dependency.**
>
> **Source tags:** **[D-NN]** = locked decision in `18-CONTEXT.md` (Tim, 2026-11-24). **[07]**…**[14]** = that phase's UI-SPEC. **[17 D-NN]** / **[16 D-NN]** = earlier CONTEXT decisions. **[FEAT §n]** = `.planning/research/FEATURES.md`. **[REPO]** = repo scouting on 2026-11-24. **[MEAS]** = computed for this spec (OKLCH → sRGB → WCAG 2.x luminance, script in the scratchpad, results identical to the 10-UI-SPEC values where they overlap; text widths estimated at JetBrains Mono 14 = 8.4 px per character, Inter estimates marked "≈"). **[UUPM]** = `ui-ux-pro-max` rule or search result. **Discretion** = an item CONTEXT handed to this spec, settled here. **Default — confirm at plan review** = a researcher default, listed again in "Defaults to Confirm".

Inherited unchanged from 07 (multiples of 4 on Tailwind's 4 px base).

| Token | Value | Tailwind | Phase 18 use |

| md | 16px | `4` | Neatline → figcaption (`mt-4`); list row gap (`gap-4`, thumbnail ↔ text); container gutter on phones (`px-4`); end-card stack gap (`gap-4`) |
| lg | 24px | `6` | Header band bottom (`pb-6`); band → header slot (`mt-6`); rail ↔ photo column (`gap-6` at md); sheet-margin row gap (`gap-x-6`); rail sticky offset from the nav (24 px) |
| xl | 32px | `8` | Header band top (`pt-8`); grid gaps between columns (`gap-8`); `/sources` entry spacing (`pt-8`) |
| 2xl | 48px | `12` | Section breaks on phones (`mt-12`, `py-12`); sequence figure spacing on phones (`gap-y-12`) |
| 3xl | 64px | `16` | Section breaks from 768 px (`md:mt-16`, `md:py-16`); sequence figure spacing from 768 px (`md:gap-y-16`) |

**Exceptions (component sizes and strokes, not spacing):**
- **Touch targets:** every button and link ≥ 44 × 44 px (`min-h-11 min-w-11`) [07]. Numbered badges draw 24 px and hit 44 px (`before:` inset), as the 10 hotspot dots [10]. Breadcrumb links are `inline-flex min-h-11`.
- **Component sizes:** numbered badge 24 px (`size-6`); exact-position dot under a displaced badge 8 px; summit triangle 12 px [09]; overview label plate `w-36` × 48 px (inset ring, as 10's plates, so the box is exactly 48 px); region-list thumbnail `w-24` (96 px, true aspect height); rail column `w-24` (96 px); Share button `min-w-42` (168 px, so the label swap never shifts layout; was `min-w-40`, amended 2026-11-25, Contract 4 note); header-slot caption row `h-11` (44 px, the Phase 19 pause control's row); trail-sign plate `min-h-14` (EndBlock) [11].
- **Strokes:** 1 px neatline (`ring-1`, takes no layout space); 1 px collar corner ticks, 8 px long; 1 px sheet-index rectangle (`vector-effect: non-scaling-stroke`); 1 px leaders; 2 px dashed outline for approximate badges [08 D-02]; 2 px accent bars (`h-0.5` / `w-0.5`) [07]; 2 px focus ring [07].
- **Geometric values:** photo boxes are `calc()` of the viewport and the photo's ratio (`--ar`), the header slot is `aspect-video`, the overview sheet is `aspect-[1200/872]` (the overview grid, `data/generated/overview.ts`), plate sheets are `aspect-square`; pin and label positions are `calc(<fraction> * 100cqw ± <n>px)` from a pure layout function, every `<n>` a scale step or a declared box constant [10 rule].
- **Banned:** half steps, arbitrary pixel spacing, `px-3` [07].

## Typography

Phase 18 uses **exactly four sizes and two weights**, all existing tokens. No `text-hero` (Home only).

| Role | Family | Size | Weight | Line height | Tailwind | Phase 18 use |
|------|--------|------|--------|-------------|----------|--------------|
| Label / data | Inter, or JetBrains Mono for data | 14px | 400 / 600 | 20px (1.43) | `text-sm` | Breadcrumb (Inter 400), kickers and data lines (Mono), collar coordinates, caption data lines, rail tick labels (Mono), badge numbers (Mono 600), overview plate name (Inter 600) and count (Mono), sheet margins (`dt` Inter, `dd` Mono), LV95 line, `/sources` labels |
| Body | Inter | 16px | 400 / 600 | 24px (1.5) | `text-base` | Facts (400), `/sources` prose and verbatim credits (400), figure titles (600), region-list names (600), button and link labels (600), trail-sign destination (600) |
| Heading | Schibsted Grotesk | 24px | 600 | 32px (1.333) | `text-heading` (base `h2`) | Section `h2`s ("Facts", "Map", "Photographs", "Next region", "Regions", each `/sources` entry), the photo title in the strip [10], the end-card heading |
| Display | Schibsted Grotesk | 40px | 600 | 44px (1.1) | base `h1` | "Photographs" on `/photos`, "Zermatt, Switzerland" on a region page, "Data sources" on `/sources` |

- **Weights** 400 and 600 only [07 DSGN-07].
- **Mono is data only and always tabular** [07]: altitudes, coordinates, dates, counts, extents, EXIF, `n / N`.
- **Body line length:** facts and `/sources` prose are `max-w-prose` (≈ 65 ch) [UUPM `line-length`].
- **No truncation anywhere.** Data lines are `whitespace-nowrap` parts joined at ` · ` and wrap only between parts (09-16 pattern); URLs and the 600-character swissALTIRegio string wrap with `wrap-anywhere` [UUPM `truncation-strategy`, `long-token-wrapping`].
- **No locale APIs.** Every number comes from the pure formatters (`lib/photo-format.ts`, `lib/home-format.ts`, `lib/footer-format.ts`), with U+00A0 before units [08, 09].

**Label layout (deterministic, server-rendered).** One pure function emits every marker, plate and summit-label position as `calc(<u> * 100cqw ± <n>px)` / `calc(<v> * 100cqh ± <n>px)` per tier, the 10 approach, so the server HTML is exact and nothing re-lays out on the client. Rules on the wide tier: no two boxes (markers, region plates, summit plates, summit triangles) overlap or come closer than 8 px; every box stays 8 px inside the sheet; a summit label that cannot be placed under these rules moves to the other side, then below; no leader crosses a box. Known tight spot: Dufourspitze's triangle sits ≈ 5 px east of the Zermatt rectangle at `S` = 736 [MEAS: (0.2389 − 0.2323) × 736]. **Gate:** a Jest sweep of every integer `S` 560–1100 (wide) and 312–559 (compact) with the real data fails on any violation, plus a guard that fails if the region or summit count changes, forcing a layout revision rather than a silent overlap [10 precedent]. The e2e asserts the same at 375, 768, 1024 and 1440.

**Compact tier (`S < 560`):** markers and rectangles only, summit triangles unlabelled; the numbers match the list badges, and the margin's Summits row names every summit (REGION-01 "numbered pins on phones").
