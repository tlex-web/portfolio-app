## Flagged assumptions

- **Optimistic state in jsdom:** a mocked `router.replace` ends the transition at once, so jsdom cannot observe the optimistic `aria-pressed` while a navigation is pending; the unit test asserts the replace call and the props round trip (rerender with new props), and the e2e asserts the immediate flip in a real browser.
- **Empty-state action as a link:** the UI-SPEC names `router.replace('/roadmap', { scroll: false })`; a `next/link` with `replace` and `scroll={false}` performs the same navigation, works without JS and needs no extra island.
- **Zero-entry combinations:** whether the data contains one depends on Tim's 11-02 rows; e2e derives the combination from the data with `countsFor` and asserts the empty state when one exists, and asserts no disabled segment when none does (no skipped test).
