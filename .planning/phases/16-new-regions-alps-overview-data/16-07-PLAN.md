## Planner decisions (not Tim decisions)

- **Sheet as a prop rather than a per-plate lookup module:** a lookup map would still grow by every plate's URLs in the footer chunk; a prop lets each caller import exactly the sheet it draws. Every caller draws the home plate today.
- **Task 2 touches seven files on purpose** (the 16-14 precedent): `ContourField`'s props are checked against every caller's JSX, so its prop change, its four callers (`SheetBand`, `PosterSheet`, `MapSheet`, `EdgeArt`), the footer line that feeds `SheetBand`, and its typed test must land in one commit for `npm run type-check` to stay green. Each caller edit is one import plus one prop swap. Splitting further would need a transitional dual-prop `ContourField` that a later commit removes, more code for no gain. Task 1 (five files) and Task 3 (one file) carry the parts that are not compile-coupled to that change: the generated module with its selftest, the legend, and the client-graph guard.
- **`components/site/__tests__/SiteFooter.test.tsx` needs no edit:** it renders `SiteFooter` without props and its D-21 static-source test reads the component files, so it runs unchanged as a guard in every task.
