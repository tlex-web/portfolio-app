- `scripts/terrain/fetch-dem.mjs`: flags `--plate <id>`, `--extent W,S,E,N`, `--force-home`, `--out <dir>` (writes to a directory outside the repo, for dry checks).
- `scripts/terrain/fetch-bev.mjs` (new): flags `--plate <id>`, `--extent W,S,E,N`, `--out <dir>`; constants `BEV_EDITION_DIR`, `CREDIT`; a bounded-retry fetch wrapper.
- `package.json`: script `terrain:fetch:bev`.
- `scripts/guards/selftest.mjs`: cases `fetch: terrain:fetch without --plate refuses and writes nothing`, `fetch: --plate matterhorn needs --force-home`, `fetch: a non-square extent is refused before any request`, `fetch: terrain:fetch:bev refuses an extent outside one BEV tile`.

## Planner decisions (not Tim decisions)

- **Two fetchers, not one with a source adapter** (Claude's discretion): the swissALTIRegio path (STAC + one national COG) and the BEV path (tile grid, overview level, retry) share little beyond the PNG write; the PNG round-trip, sha256 and "nothing written" footer are copied, as PATTERNS suggests.
- **No multi-tile concatenation:** D-28's plate lies in one tile; the fetcher refuses a window that needs more and names the tiles, and the `tiles` array in the schema keeps the format open for it.
- **`--out <dir>`** lets the executor dry-run a fetch into the scratchpad without touching `data/`.
