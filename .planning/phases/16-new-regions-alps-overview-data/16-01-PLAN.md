## Planner decisions (not Tim decisions)

- **Staging instead of an exclusion list (orchestrator note 3, D-28's open call):** the executor moves every unrecorded original into the gitignored `assets/photos-original/incoming/`. `listOriginals()` reads only the top level, so extraction skips them with no code path and no file name committed. 16-14 later moves the excluded files (no GPS, outside the plate) to `assets/photos-original/not-in-series/`. Reversible: moving files back.
- **Precision on every generated position, kind on every photo fact:** required, not optional, following D-02's no-default rule. Key order is `lat, lon, precision, source, approximate, …` and `id, region, country, kind, …`, so the generated diff for the four current photos is additions only.
- **Hand-placed positions take their record's precision** and stage 2 refuses a corrections position finer than it, so a correction can never undo a coarse choice.
- **Coarse photo copy rule** (applies at 16-08 / 16-17): copy never names a place finer than the photo's precision cell.
