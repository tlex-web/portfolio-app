<task type="auto">
  <name>Task 2: Expand globals.css reduced-motion block with universal animation gating</name>
  <files>app/globals.css</files>
  <action>
Expand the existing `@media (prefers-reduced-motion: reduce)` block in `globals.css` (currently at ~line 349) to include:

1. Gate Tailwind animation utilities:
```css
.animate-pulse {
  animation: none;
}
.animate-spin {
  animation: none;
}
.animate-bounce {
  animation: none;
}
```

2. Add universal transition/animation fallback as the LAST rule in the block (after specific class rules):
```css
*,
*::before,
*::after {
  transition-duration: 0.01ms !important;
  animation-duration: 0.01ms !important;
  animation-iteration-count: 1 !important;
}
```

Use `0.01ms` instead of `0s` to avoid breaking JavaScript that listens for `transitionend` events. The `!important` on the universal selector ensures it catches animations not covered by component-level `useReducedMotion` gating.

Keep all existing Phase 4 guards (contour-animate, ambient-glow, glow-frost, glow-ember) intact above the new additions.

The final block should read:
```css
@media (prefers-reduced-motion: reduce) {
  /* Phase 4 guards */
  .contour-animate {
    animation: none;
  }
  .ambient-glow::after {
    transition: none;
  }
  .glow-frost,
  .glow-ember {
    transition: none;
  }

  /* Phase 5: Tailwind animation utilities */
  .animate-pulse,
  .animate-spin,
  .animate-bounce {
    animation: none;
  }

  /* Phase 5: Universal fallback -- catches all CSS transitions and animations */
  *,
  *::before,
  *::after {
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
  }
}
```
