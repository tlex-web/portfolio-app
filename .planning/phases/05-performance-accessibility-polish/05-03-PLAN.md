1. Add `import { useReducedMotion } from '@/lib/useReducedMotion';`
2. Call `const prefersReducedMotion = useReducedMotion();` at the top of the component function
3. Gate all Framer Motion animation props using these rules:

**Entrance animations (`initial`/`animate`):**
- `initial={prefersReducedMotion ? false : { opacity: 0, y: 20 }}` -- skip entrance, render in final position
- Keep `animate` prop unchanged (Framer Motion applies target values immediately when initial is false)
- `transition={prefersReducedMotion ? { duration: 0 } : { ...existing transition }}`

**Gesture animations (`whileHover`/`whileTap`):**
- `whileHover={prefersReducedMotion ? undefined : { ...existing }}` -- disable hover effect
- `whileTap={prefersReducedMotion ? undefined : { ...existing }}` -- disable tap effect

**layoutId animations:**
- Keep `layoutId` prop but add `transition={prefersReducedMotion ? { duration: 0 } : { ...existing }}`

**Component-specific gating:**

**ProjectHighlights.tsx:** Gate entrance fade/slide with stagger. The `motion.div` elements with `initial={{ opacity: 0, y: 20 }}` and stagger delay need gating on `initial` and `transition`.

**FeatureShowcase.tsx:** Gate entrance fade, `whileHover` scale, and any `layoutId` transitions. Check for `whileHover={{ scale: ... }}` patterns and gate them.

**TechStackDisplay.tsx:** Gate entrance scale animations and `whileHover` scale + y-shift effects.

**TerminalDemo.tsx:** This component uses `setInterval` for character-by-character typing. When reduced motion is on:
- Skip the typing animation entirely by setting the display text to the full command/output string immediately instead of character-by-character reveal.
- Look for the `setInterval` or typing loop logic. When `prefersReducedMotion` is true, set the full text in the state directly without the interval delay.
- Also gate any `AnimatePresence` entrance animations with `initial={prefersReducedMotion ? false : { ... }}`.

**HologramTerminalDemo.tsx:** Same pattern as TerminalDemo -- if it has a typing animation, show full text immediately when reduced motion is on. Gate entrance fade animations.
