# Plan 01-03: Fix blurDataURL prop warning in GalleryGrid test

## Goal
Eliminate the React console.error warning about unrecognized `blurDataURL` prop in GalleryGrid test by updating the Next.js Image mock to destructure Next.js-specific props.

## Root Cause
The Next.js Image mock in `components/__tests__/GalleryGrid.test.tsx` only destructures `fill` from props, spreading all remaining props (including `blurDataURL`, `placeholder`, `loading`, `sizes`) to a plain `<img>` DOM element. These are Next.js Image-specific props that a native `<img>` doesn't recognize.

## Tasks

### Task 1: Update Image mock to filter Next.js-specific props

**File:** `components/__tests__/GalleryGrid.test.tsx`

**Change line 10 from:**
```typescript
const { fill, ...rest } = props;
```

**To:**
```typescript
const { fill, blurDataURL, placeholder, loading, sizes, ...rest } = props;
```

**Verification:**
- Run `npx jest components/__tests__/GalleryGrid.test.tsx` — all tests pass with no console.error warnings about unrecognized props
