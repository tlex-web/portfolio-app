<task type="auto">
  <name>Task 1: Create proxy.ts with nonce-based CSP</name>
  <files>proxy.ts, next.config.ts</files>
  <action>
    Create `proxy.ts` at project root (Next.js 16 convention, NOT middleware.ts).

    The proxy function must:
    1. Generate a per-request nonce: `Buffer.from(crypto.randomUUID()).toString('base64')`
    2. Build CSP header string with these directives:
       - `default-src 'self'`
       - `script-src 'self' 'nonce-${nonce}' 'strict-dynamic' 'unsafe-eval'` (unsafe-eval kept for Three.js shaders per user decision; strict-dynamic allows nonce-loaded scripts to load dependencies)
       - `style-src 'self' 'nonce-${nonce}'`
       - `img-src 'self' blob: data:` (blob: needed for Three.js textures, data: for inline images)
       - `font-src 'self' data:`
       - `connect-src 'self'` (Vercel Analytics uses same-origin /_vercel/ endpoints)
       - `frame-src 'none'` (no external embeds per user decision)
       - `object-src 'none'`
       - `base-uri 'self'`
       - `form-action 'self'`
       - `frame-ancestors 'none'`
       - `upgrade-insecure-requests`
    3. Set the nonce in request header `x-nonce` (Next.js reads this to auto-inject into framework scripts)
    4. Set `Content-Security-Policy` on BOTH request headers and response headers
    5. Collapse whitespace in CSP string (.replace(/\s{2,}/g, ' ').trim())

    Export config.matcher to skip: api routes, _next/static, _next/image, favicon.ico, service-worker.js, and prefetch requests. Use the exact matcher pattern from the Next.js 16 CSP docs.

    In `next.config.ts`:
    - Remove the entire `Content-Security-Policy` header block from the `headers()` function (lines inside the `if (process.env.NODE_ENV === 'production')` block that set CSP)
    - KEEP the other security headers (X-Content-Type-Options, X-Frame-Options, X-XSS-Protection, Referrer-Policy, Permissions-Policy) -- move them OUTSIDE the production-only condition so they apply in all environments
    - KEEP the cache headers for /images/ and /_next/static/
    - Remove the `process.env.NODE_ENV === 'production'` condition wrapper entirely since CSP is now in proxy.ts and the remaining security headers should apply always
  </action>
  <verify>
    Run `npx tsc --noEmit` to verify proxy.ts compiles without type errors.
    Visually confirm proxy.ts exports a `proxy` function and a `config` object with matcher.
    Visually confirm next.config.ts no longer has Content-Security-Policy in headers but retains cache headers and other security headers.
  </verify>
  <done>proxy.ts exists at project root, exports proxy function that generates nonce-based CSP. next.config.ts has no CSP header (moved to proxy.ts) but retains all other headers.</done>
</task>
