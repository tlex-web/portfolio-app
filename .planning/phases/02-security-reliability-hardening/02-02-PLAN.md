<task type="auto">
  <name>Task 1: Install Upstash packages and create CSRF + rate limit utilities</name>
  <files>lib/csrf.ts, lib/rate-limit.ts, .env.example, package.json</files>
  <action>
    **Step 1: Install packages**
    Run `npm install @upstash/ratelimit @upstash/redis`

    **Step 2: Create lib/csrf.ts**
    Export a `validateOrigin(request: Request): boolean` function that:
    - Gets the `Origin` header from the request
    - Gets the `Host` header from the request
    - If Origin is absent/null, return `true` (same-origin requests may omit Origin; cross-origin POST always includes it per Fetch spec)
    - If Origin is present, parse it with `new URL(origin).host` and compare to `host`
    - Return true if they match, false otherwise
    - This is the same mechanism Next.js Server Actions use internally (research-recommended, Claude's discretion)

    **Step 3: Create lib/rate-limit.ts**
    Export a `feedbackRateLimit` object. Implementation:
    - Import `Ratelimit` from `@upstash/ratelimit` and `Redis` from `@upstash/redis`
    - Use lazy initialization pattern: check if `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` are set
    - If env vars present: create `new Ratelimit({ redis: Redis.fromEnv(), limiter: Ratelimit.slidingWindow(5, '1 h'), analytics: true, prefix: 'ratelimit:feedback' })`
    - If env vars missing (development): export a mock object with a `.limit()` method that always returns `{ success: true, limit: 5, remaining: 5, reset: 0 }` and logs a warning once that rate limiting is disabled
    - Export the rate limiter as `feedbackRateLimit` with a `.limit(identifier: string)` method signature
    - The 5 per hour and feedback-only scope are per user decision (locked)

    **Step 4: Update .env.example**
    Add a new section for Upstash Redis:
    ```
    # Rate Limiting (Required for persistent rate limiting)
    # Create a free Redis database at https://console.upstash.com
    # Or provision via Vercel Marketplace -> Upstash integration (auto-injects env vars)
    # UPSTASH_REDIS_REST_URL=https://your-database.upstash.io
    # UPSTASH_REDIS_REST_TOKEN=your_token_here
    ```
  </action>
  <verify>
    Run `npx tsc --noEmit` to verify lib/csrf.ts and lib/rate-limit.ts compile.
    Verify @upstash/ratelimit and @upstash/redis appear in package.json dependencies.
    Read .env.example to confirm Upstash vars are documented.
  </verify>
