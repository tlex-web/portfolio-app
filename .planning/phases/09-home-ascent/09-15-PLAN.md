       - It wraps window.requestAnimationFrame and window.cancelAnimationFrame. Every callback is scheduled on the native requestAnimationFrame through a trampoline; when a trampoline runs while the model is hidden, it queues its callback instead of calling it. This also holds callbacks requested before the hide.
       - It counts native frames (distinct rAF timestamps) that start while document.querySelector('[data-ascent-stage]') reads data-ascent-mode '3d'. At the start of the frame that would exceed hideAfterFrames, before any callback of that frame runs, it hides: sets the hidden flag, redefines document.visibilityState as 'hidden' and document.hidden as true (configurable getters, as setVisibility does), dispatches 'visibilitychange' on document and records window.__tab.hiddenAt = performance.now().
       - window.__tab.show() redefines visibilityState 'visible' and hidden false, dispatches 'visibilitychange', records shownAt = performance.now(), then requests one native frame in which it clears the hidden flag and runs every queued callback with that frame's timestamp, in queue order (Chromium fires visibilitychange before the held frame: debug Resolution).
