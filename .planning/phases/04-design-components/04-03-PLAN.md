**Create `lib/useHexGrid.ts`:**

A 'use client' hook that manages hex grid row offset logic.

```typescript
export function useHexGrid(containerRef: React.RefObject<HTMLElement | null>, itemCount: number)
```

1. On mount and on resize (use ResizeObserver), calculate items per row from container width and `--hex-size` CSS variable (or fallback 340px).
2. For each child element, determine if it's in an even row (0-indexed). If so, add class `hex-offset`. If odd row, remove it.
3. Clean up ResizeObserver on unmount.
4. On mobile (container width < 768px), remove all `hex-offset` classes (single column, no stagger).
5. Return nothing (side-effect only hook).

**Redesign `components/ProjectCard.tsx`:**

Complete visual overhaul. Keep the `ProjectCardProps` interface and all data display logic. Replace ALL styling.

1. **Imports:** Add `useRef, useCallback` to React imports. Add `motion, useMotionValue, animate` from 'framer-motion'. Add `EASING, DURATION, TILT_CONFIG` from '@/lib/animations'. Add `useReducedMotion` from '@/lib/useReducedMotion'.

2. **Two-layer card structure** (critical for glow + clip-path):

Outer wrapper: `motion.div` that handles glow and tilt transform. Does NOT have clip-path. Has `ambient-glow stratum-2` classes for glow and depth shadow. This is the element that receives `style={{ rotateX, rotateY, transformPerspective: TILT_CONFIG.perspective, transformStyle: 'preserve-3d' }}`.

Inner content: `div` with `hex-clip` class (clip-path polygon). Background `bg-alpine-800/90 backdrop-blur-sm`. Contains all card content with generous padding (`p-6 sm:p-8`). The hex clip-path clips corners, so content must have padding to avoid being cut.

3. **Tilt/parallax hover effect:**
   - `const rotateX = useMotionValue(0)` and `const rotateY = useMotionValue(0)`.
   - `handleMouseMove`: Calculate cursor position relative to card center. Set `rotateX` and `rotateY` with max TILT_CONFIG.maxRotation (12 degrees).
   - `handleMouseLeave`: Use `animate(rotateX, 0, { duration: DURATION.settle, ease: EASING.geological })` and same for `rotateY`. This is the geological "settle back to rest" effect.
   - Gate behind `!prefersReducedMotion`.

4. **Facet reveal on hover:** On hover, the inner hex-clip element shows a subtle gradient overlay that simulates light catching crystalline edges. Use a `motion.div` overlay inside the hex-clip with `bg-gradient-to-br from-frost-500/5 via-transparent to-frost-500/8` that fades in on hover. Also increase glow intensity (ambient-glow::after opacity increases via parent hover state already in CSS).

5. **Card entrance animation:** Replace current `initial/animate/whileHover` with:
   - `initial={{ opacity: 0, y: 30, scale: 0.95 }}`
   - `whileInView={{ opacity: 1, y: 0, scale: 1 }}`
   - `transition={{ delay: index * 0.08, duration: DURATION.enter, ease: EASING.crystallize }}`
   - `viewport={{ once: true }}`
   Remove the old `whileHover={{ y: -8 }}` -- the tilt effect replaces it.
