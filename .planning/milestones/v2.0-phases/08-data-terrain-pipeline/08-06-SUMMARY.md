**Immutable, CSP-free `/terrain/` delivery with an SW precache of the footer strip (injected from a generated precache.json), and a hashed greyscale NW-lit hillshade poster (AVIF/WebP, 1100 and 640 px) bound to the committed DEM by `terrain:build --check`, approved by Tim without tuning**

## Accomplishments

- `/terrain/*` responses carry `public, max-age=31536000, immutable`, and the proxy matcher skips `images/` and `terrain/`, so static assets get no per-request CSP nonce while every page keeps its CSP (checked on a local production server).
- The service worker precaches `['/', '/offline', ...PRECACHE]`, where PRECACHE is injected at postbuild from `data/generated/precache.json` (the hashed strip SVG), and serves `/terrain/` cache-first, so `/offline` keeps its footer band.
- D-16 poster: four hashed, metadata-free files (`hillshade-1100.5b6bae8c54.webp` 194 KB, `hillshade-1100.ba22a91f95.avif` 112 KB, `hillshade-640.80f2045ea4.webp` 67 KB, `hillshade-640.b019a3335a.avif` 38 KB), listed in `terrain.assets.hillshade` with `sourceSha256`. The encode is deterministic on this machine: a rebuild gave the same four hashes.
- `terrain:build --check` fails, naming the file, when a poster's hash does not match its bytes, its size is wrong, it carries metadata, it came from a different source raster, a shading parameter changed without a rebuild, or an extra hashed file is present.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] Shading parameters recorded in terrain.ts**
- **Found during:** Task 2
- **Issue:** The plan bound the poster only to the source raster. A tuning edit to the light or gamma parameters that was not rebuilt would still pass `--check`.
- **Fix:** `terrain.ts` gains a top-level `hillshade` block with the parameters next to `assets.hillshade { avif, webp, sourceSha256 }`. `--check` compares it with the script's `HILLSHADE` block. Phase 9 can read the light direction from it.
- **Files modified:** scripts/terrain/build-terrain.mjs, data/schemas/terrain.ts, data/generated/terrain.ts
- **Verification:** Tamper case: changing a HILLSHADE parameter makes the four posters and terrain.ts stale (exit 1).
- **Committed in:** 865ca82

**2. [Rule 2 - Missing Critical] Write mode keeps a passing committed poster set**
- **Found during:** Task 2
- **Issue:** Lossy encoders are not byte-stable across platforms (RESEARCH A1), so a rebuild on another machine would rename the posters even with identical inputs.
- **Fix:** Like the 08-04 heightmaps, write mode keeps the committed poster set when it already passes every check.
- **Files modified:** scripts/terrain/build-terrain.mjs
- **Verification:** A rebuild gave the same four hashes; `--check` OK.
- **Committed in:** 865ca82

**3. [Rule 2 - Missing Critical] Injector hardening (T-08-17)**
- **Found during:** Task 1
- **Issue:** The plan required URLs to start with `/terrain/`. A string replacement with `$` patterns in the JSON could also be misread by `String.replace`.
- **Fix:** The injector accepts only content-hashed `/terrain/` URLs and replaces the token through a function.
- **Files modified:** scripts/inject-build-hash.mjs
- **Verification:** Build + `node --check` + "sw injected"; precache tests.
- **Committed in:** d035090

**4. [Process] The plan's build verify wiped uncommitted SW edits once**
- **Found during:** Task 1
- **Issue:** The verify command ends with `git checkout -- public/service-worker.js`, which discarded the uncommitted SW edits the first time it ran.
- **Fix:** Re-applied the edits, committed them, then re-ran the verify.
- **Files modified:** public/service-worker.js
- **Verification:** The committed SW contains `__PRECACHE_URLS__`, `'__BUILD_HASH__'` and `startsWith('/terrain/')`; `git status` was clean after the verify.
- **Committed in:** d035090

**5. [Process] Bash heredoc backslash halving**
- **Found during:** Task 1/2 test authoring
- **Issue:** The Bash tool halves backslashes in heredocs, which broke one test regex.
- **Fix:** Fixed the regex with Edit and checked every committed regex.
- **Committed in:** d035090 / 865ca82
