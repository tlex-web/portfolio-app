# Phase 12 Plan 30: Service worker keeps what it saves Summary

**The hero contour SVG now ships in the install precache, written by the terrain build (C2). Every service-worker cache write goes through `storeCopy`, which hands an `open → put → catch` chain to `event.waitUntil`. The browser can no longer stop the worker mid-write, and a full quota stays quiet (WR-04).**
