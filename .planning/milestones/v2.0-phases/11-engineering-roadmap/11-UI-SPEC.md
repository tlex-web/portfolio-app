## Typography

Phase 11 uses **exactly four sizes and two weights**, all existing tokens. It does not use `text-hero` (Home only).

| Role | Family | Size | Weight | Line height | Tailwind | Phase 11 use |
|------|--------|------|--------|-------------|----------|--------------|
| Label / data | Inter, or JetBrains Mono for data | 14px | 400 / 600 | 20px (1.43) | `text-sm` | Kickers (Mono), metric labels (`dt`), context lines, profile captions (Mono), grade text in badges (Mono), terminal and preview bodies (Mono), terminal notes (Inter), route-row meta lines (Mono), segment counts (Mono), stack chips, preview and release context lines |
| Body | Inter | 16px | 400 / 600 | 24px (1.5) | `text-base` | Prose and section intros (400), Privacy facts and the `--force` line (400), the clip description (400), h3 group labels and route-row titles (600), button and segment labels (600), pipeline stage names (600), route-index links (400) |
| Heading | Schibsted Grotesk (Inter 400 for the outcome line; Mono 600 for metric values) | 24px | 600 | 32px (1.333) | `text-heading` | h2 section and band headings, panel h2 titles; the trailhead outcome line (Inter 400, the 09 thesis precedent); metric values (Mono 600, the 09 summit-height precedent) |
| Display | Schibsted Grotesk | 40px | 600 | 44px (1.1) | `text-display` (base `h1`) | `Engineering`, the case-study h1 (project name), `Roadmap` |

- **Weights:** 400 and 600 only [07 DSGN-07]. The v1 `font-bold`, `font-medium`, `text-5xl`, `text-xl`, `text-xs` and glow text-shadows on these pages are removed.
- **Mono is data only and always tabular** [07]: versions, counts, dates, metric values, commands and command output. Titles, prose, labels, notes and buttons are Inter or Schibsted. A metric that the audit softens to a word (for example "Offline") is not set in Mono; see Metrics.
- **No locale APIs.** New pure formatter `formatLogDate('2026-10-24')` → `24 Oct 2026` (three-letter English month from a fixed array, the `formatCaptureMonth` table [09]; import-free, unit-tested). Ranges use an en dash U+2013 (`T2–T3`, `Phases 7–12`).
- **No truncation anywhere.** Text wraps. Separator-joined lines use `whitespace-nowrap` units joined by ` · ` so they break only between units (the 09-16 pattern; 10-UI-REVIEW fix 2 applied to every Phase 11 meta line from the start) [UUPM `truncation-strategy`, `compact-label-overflow`]. Long commands, output lines, hashes and URLs use `wrap-anywhere` [UUPM `long-token-wrapping`].
- **Headings:** h1 and h2 get `text-balance` [07; UUPM `heading-line-balance`].
- **Project names** render as the repositories spell them: `box`, `coin-flip` (lowercase, also as the h1). Default (researcher) — confirm at plan review (N1).

## Shared Marks

### `TrailGradeMark` (Server, zero JS) [D-06, D-24 vocabulary]

One component draws the waymark for a grade. Box 16 × 12 px, `inline-flex shrink-0`, `aria-hidden="true"`; it is **always followed by visible grade text** (never alone). It reads its marker from the grade → marker map kept in `lib/trail-grade.ts` (the score bands leave that file, D-24). Trail grades appear **only** as the real SAC grade of the trail a project's profile glyph draws (D-06): on the route panel and on the trailhead. Nowhere else on the site uses this vocabulary.

| Marker | Grades | Drawing |
|--------|--------|---------|
| `yellow` | T1 | A 12 × 12 px diamond centred in the box: `bg-trail` with `clip-path: polygon(50% 0, 100% 50%, 50% 100%, 0 50%)` (the Swiss hiking-trail rhombus) |
| `white-red-white` | T2–T3 | Three stacked 4 px bars, full width: `bg-trail-blaze` / `bg-trail-mountain` / `bg-trail-blaze` |
| `white-blue-white` | T4–T5 | Same, with `bg-trail-alpine` in the middle |
| `unmarked` | T6 | A 16 × 12 px box with `border border-dashed border-ink-muted` and no fill: the 08 dashed "not exact" convention, so it reads as "no paint here", not as a missing image |

The shape differs between T1 (diamond), T2–T5 (bars) and T6 (dashed box); T2–T3 and T4–T5 differ by hue only, which is why the grade text is mandatory beside every glyph and the waymark name is in the accessible text [UUPM `color-not-only`, `pattern-texture`].

**Badge format:** `[glyph] T4` inside the profile caption. Grade in Mono `text-sm text-ink`; the unit `· [glyph] T4` is `whitespace-nowrap`; the ` · ` separator is `aria-hidden`. Accessible text adds the waymark name (sr-only): "T4, white-blue-white waymark"; "T1, yellow waymark".
