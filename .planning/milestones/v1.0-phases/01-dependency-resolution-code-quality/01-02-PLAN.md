    Remove the `thumbnail`, `medium`, `large`, and `original` entries. The new suffix naming (`-sm`, `-md`, `-lg`) avoids colliding with existing `-thumb`, `-medium`, `-large` files.

    ```javascript

    quality: {
      webp: 82,
      avif: 50,
      jpeg: 82,
    },
    ```
    AVIF quality 50 produces comparable visual quality to JPEG 82 due to superior compression. Effort 4 (default) balances encode speed and file size.

    **4. Add AVIF processing branch** in the format loop:
    ```javascript
    } else if (format === 'avif') {
      processor = processor.clone().avif({
        quality: config.quality.avif,
        effort: 4,
      });
    }
    ```
    Also update the extension mapping: `const ext = format === 'jpeg' ? 'jpg' : format;` already handles 'avif' correctly (produces `.avif`).

    **5. This prevents the prebuild step from re-running on every build when images haven't changed.

    **6. Handle missing input gracefully** — If no source images are found (e.g., in CI where only optimized files exist), exit 0 with a message like "No source images found, skipping optimization" instead of exit 1. This prevents build failures in CI.
