<task type="auto">
  <name>Task 2: Integrate Google Fonts and define base typography hierarchy</name>
  <files>app/layout.tsx, app/globals.css</files>
  <action>
**In `app/layout.tsx`:**

1. Add imports for fonts at the top:
   ```typescript
   import { Inter, JetBrains_Mono } from 'next/font/google';
   ```

2. Initialize the font instances OUTSIDE the component (module scope):
   ```typescript
   const inter = Inter({
     subsets: ['latin'],
     variable: '--font-inter',
     display: 'swap',
   });

   const jetbrainsMono = JetBrains_Mono({
     subsets: ['latin'],
     variable: '--font-jetbrains',
     display: 'swap',
   });
   ```

3. Add font variable classes to the `<html>` element (NOT `<body>` — this is critical for @theme inline resolution):
   ```tsx
   <html lang="en" className={`${inter.variable} ${jetbrainsMono.variable}`}>
   ```

4. Add `font-body` class to `<body>`:
   ```tsx
   <body className="font-body antialiased">
   ```

5. Keep all existing content: nonce reading, metadata export, ServiceWorkerRegistration, Analytics, SpeedInsights, head resource hints.

**In `app/globals.css`:**

1. Add `@theme inline` block BEFORE the `@theme` block (or as a separate block — both work). This wires next/font CSS variables to Tailwind font tokens:
   ```css
   @theme inline {
     --font-body: var(--font-inter);
     --font-heading: var(--font-jetbrains);
     --font-mono: var(--font-jetbrains);
   }
   ```
   Use `@theme inline` (NOT regular `@theme`) because these reference runtime CSS variables from next/font that aren't available at build time.

2. Add `@layer base` block AFTER the `@theme` block but BEFORE the existing `@layer utilities` block. Define the typography hierarchy:

   ```css
   @layer base {
     body {
       font-family: var(--font-body);
       color: var(--color-snow-100);
       background-color: var(--color-alpine-900);
     }

     h1 {
       font-family: var(--font-heading);
       font-weight: 700;
       font-size: 2.5rem;
       line-height: 1.2;
       color: var(--color-snow-50);
       text-shadow: var(--text-shadow-glow-lg);
     }

     h2 {
       font-family: var(--font-heading);
       font-weight: 600;
       font-size: 1.875rem;
       line-height: 1.3;
       color: var(--color-snow-50);
     }

     h3 {
       font-family: var(--font-heading);
       font-weight: 500;
       font-size: 1.5rem;
       line-height: 1.4;
       color: var(--color-snow-100);
     }

     h4 {
       font-family: var(--font-heading);
       font-weight: 500;
       font-size: 1.25rem;
       line-height: 1.4;
       color: var(--color-snow-100);
     }

     small, .caption {
       font-size: 0.875rem;
       line-height: 1.5;
       color: var(--color-granite-400);
     }
   }
   ```

3. Remove the old `body { color: var(--foreground); background: var(--background); font-family: Arial, Helvetica, sans-serif; }` block since it's replaced by the `@layer base body` rule above.

**CRITICAL RULES:**
- Font variables MUST go on `<html>`, not `<body>` — Tailwind's `@theme` resolves at `:root` level
- Use `@theme inline` for font vars, regular `@theme` for literal color values
- The `@layer base` body rule replaces the old unscoped body rule — remove the old one to avoid conflicts
- Keep the heading glow conservative: `var(--text-shadow-glow-lg)` is 20px blur at 30% opacity
  </action>
