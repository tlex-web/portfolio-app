  <action>
Modify CSP header in proxy.ts (lines 6-19) to fix two blocking issues:

**1. Add 'unsafe-inline' to style-src (line 9):**
Change from:
```
style-src 'self' 'nonce-${nonce}';
```
To:
```
style-src 'self' 'nonce-${nonce}' 'unsafe-inline';
```

**Why:** React's style prop (style={{ ... }}) generates inline style *attributes* on DOM elements, not style *elements*. Per CSP spec, nonces can only be applied to `<style>` elements, NOT style attributes. The only way to allow style attributes is 'unsafe-inline'. This affects:
- React DOM style prop usage (25+ occurrences across components)
- @react-three/fiber Canvas component (injects inline styles on divs/canvas)
- @react-three/drei Html component (wrapper divs with positioning styles)

Note: This does NOT weaken script-src security. script-src remains nonce-based with no 'unsafe-inline'.

**2. Add https://raw.githack.com to connect-src (line 12):**
Change from:
```
connect-src 'self';
```
To:
```
connect-src 'self' https://raw.githack.com;
```

**Why:** @react-three/drei Environment component with preset= prop fetches HDRI .hdr files from https://raw.githack.com/pmndrs/drei-assets/... CDN. This app uses three presets:
- "night" (HologramTerminal.tsx, MountainTerrain3D.tsx)
- "city" (PhotoCarousel3D.tsx)
- "sunset" (TransitionShowcase.tsx)

Without this domain, fetch requests fail causing WebGLRenderer Context Lost and complete 3D component crashes.

**Implementation:**
- Edit proxy.ts lines 9 and 12 with the changes above
- Maintain existing formatting (multi-line CSP string)
- Keep all other CSP directives unchanged
- Do not touch matcher config (lines 43-54)
