**Create `components/ContourBackground.tsx`:**

A 'use client' component that renders 5-8 inline SVG topographic contour paths as a decorative background. Accept props: `opacity: number` (0-1), `className?: string`.

- SVG uses `viewBox="0 0 800 80"`, `preserveAspectRatio="none"`, positioned `absolute inset-0 w-full h-full pointer-events-none`.
- Create 5-8 `<path>` elements with flowing quadratic/cubic bezier curves at varying Y positions (mimicking topographic contour lines). Each path has `fill="none"`, `stroke="var(--color-frost-500)"`, varying `strokeWidth` (0.3-0.8) and `strokeOpacity` (0.1-0.4).
- Wrap paths in a `<g>` element that has the `contour-animate` class (CSS keyframe from globals.css). Make the SVG wider than the container (200% width) so the translateX animation creates an infinite scrolling effect.
- The outer SVG takes `style={{ opacity }}` for scroll-linked fade control.
- Import `useReducedMotion` from `@/lib/useReducedMotion`. If reduced motion, remove the `contour-animate` class.

**Redesign `components/GlassmorphismNav.tsx`:**

Completely restyle. Keep the existing navigation data structure and routing logic. Replace ALL CSS classes with design token equivalents. Remove all `dark:` prefixes and gray/white color classes.

Key changes:

1. **Imports:** Add `motion, useScroll, useTransform, AnimatePresence` from 'framer-motion'. Add `EASING, DURATION` from '@/lib/animations'. Add `useReducedMotion` from '@/lib/useReducedMotion'. Add ContourBackground component.

2. **Scroll-progressive glass effect:**
   - Use `useScroll()` to get `scrollY`.
   - Use `useTransform(scrollY, [0, 150], [0, 1])` to derive a `scrollProgress` value.
   - Use `useTransform` to map scrollProgress to:
     - `bgOpacity`: [0, 0.85] -- background opacity goes from transparent to near-opaque
     - `blurValue`: [0, 16] -- backdrop blur intensifies with scroll
     - `contourOpacity`: [0, 0.6] -- contour lines fade in as you scroll
   - Apply these as inline styles on the nav element: `backgroundColor: alpine-900 with dynamic opacity`, `backdropFilter: blur(dynamic)`.

3. **Nav background structure:**
   - Outer `<motion.nav>` with `fixed top-0 left-0 right-0 z-50`.
   - Inside nav: `<ContourBackground opacity={contourOpacityValue} />` positioned absolutely behind content.
   - Nav content sits on top with relative positioning.

4. **Logo/brand:** Replace `bg-gradient-to-br from-cyan-500 to-blue-600` with `bg-frost-500` or `bg-gradient-to-br from-frost-500 to-frost-600`. Replace `text-white` with `text-snow-50`. Replace `shadow-cyan-500/50` with `shadow-frost-500/50`.

5. **Desktop nav links:**
   - Active state: `bg-frost-500/20 text-snow-50 glow-frost` (frost glow from globals.css utility).
   - Hover state: `hover:bg-alpine-700/50 hover:text-snow-50`.
   - Default: `text-snow-200`.
   - Use `motion.div` with `layoutId="activeNavIndicator"` for animated active indicator that slides between tabs. Use geological easing: `transition={{ type: "tween", duration: DURATION.hover, ease: EASING.geological }}`.

6. **Mobile menu button:** Replace `text-white hover:bg-white/10` with `text-snow-100 hover:bg-alpine-700/50`. Keep 44px min touch target.

7. **Mobile overlay (MAJOR REDESIGN):**
   - Replace the current slide-in panel with a FULL-SCREEN overlay (`fixed inset-0 z-50`).
   - Background: `bg-alpine-950/95 backdrop-blur-xl` with ContourBackground at opacity 0.4.
   - Use `AnimatePresence` with `motion.div` for enter/exit animations using geological easing.
   - Navigation links: Large touch targets (`min-h-[56px]`), `text-2xl font-heading`, centered vertically.
   - Active link gets frost glow. Hover links get subtle frost tint.
   - Close button: top-right, 48px touch target.
   - Links stagger in with `motion.div` using `EASING.crystallize` and 50ms delays.

8. **Token migration checklist for this file:**
   - `bg-white/10 dark:bg-gray-900/10` -> removed, replaced by dynamic alpine-900 opacity
   - `text-white` -> `text-snow-50` or `text-snow-100`
   - `text-white/90` -> `text-snow-200`
   - `bg-white/20` -> `bg-frost-500/20`
   - `hover:bg-white/10` -> `hover:bg-alpine-700/50`
   - `dark:bg-gray-900/10` -> removed (dark-only site)
   - All `dark:` prefixes -> removed
   - `focus:ring-white/20` -> `focus:ring-frost-500/30`

9. **Reduced motion:** Gate all scroll-linked transforms and stagger animations behind `useReducedMotion()`. If reduced motion, nav shows its scrolled state immediately (no progressive reveal), no stagger on mobile links.
