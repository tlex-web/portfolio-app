  <name>Task 1: Create geological easing constants and scroll-linked glow hook</name>
  <files>lib/animations.ts, lib/useGlowIntensity.ts</files>
  <action>
Create `lib/animations.ts` with the following exports:

1. `EASING` object with cubic-bezier arrays for Framer Motion `transition.ease`:
   - `geological`: [0.22, 0.61, 0.36, 1.0] -- stone shifting into place, slow start, decisive arrival
   - `crystallize`: [0.16, 0.85, 0.45, 1.0] -- builds slowly, snaps into structure
   - `tectonic`: [0.33, 0.0, 0.2, 1.0] -- very slow start, powerful finish
   - `erosion`: [0.4, 0.0, 0.2, 1.0] -- gradual, patient, revealing
   All typed as `readonly [number, number, number, number]`.

2. `DURATION` object:
   - `hover`: 0.35 -- hover state changes (300-400ms range)
   - `enter`: 0.45 -- page enter animations
   - `settle`: 0.5 -- tilt settle back to rest
   - `fracture`: 0.3 -- crystal fracture on click
   All typed as numbers (seconds for Framer Motion).

3. `TILT_CONFIG` object:
   - `maxRotation`: 12 -- max degrees of tilt
   - `perspective`: 600 -- CSS perspective value in px

Mark all objects with `as const`. Add 'use client' directive since these may be imported in client components. Use TypeScript types, not `any`.

Create `lib/useGlowIntensity.ts` as a 'use client' hook:

1. Import `useScroll`, `useTransform`, `useMotionValueEvent` from 'framer-motion'.
2. Import `useReducedMotion` from '@/lib/useReducedMotion'.
3. Use `useScroll()` (no target, tracks window scroll).
4. Use `useTransform(scrollY, [0, 800], [1.0, 0.15])` to map scroll position to glow intensity.
5. Use `useMotionValueEvent(glowIntensity, 'change', ...)` to write `--glow-intensity` to a container element.
6. Accept an optional `containerRef` parameter (React.RefObject<HTMLElement | null>). If provided, set the CSS variable on that element. If not, set on `document.documentElement`.
7. If `prefersReducedMotion` is true, set `--glow-intensity` to `0.3` (static, muted) and skip scroll tracking.
8. Return the `glowIntensity` motion value for any component that wants to read it directly.
9. Clean up: reset `--glow-intensity` on unmount.

Follow existing codebase conventions: named export, JSDoc comment, camelCase.
  </action>
